# L2. Table with grouped headers

Write a complete document holding one table (`booktabs`, no vertical lines, label `tab:krylov`, caption "Krylov solver cost") with this data:

| Dimension | N | CG iterations | CG time | GMRES iterations | GMRES time |
|---|---|---|---|---|---|
| 2D | 64 | 112 | 0.42 | 98 | 0.57 |
| 2D | 128 | 225 | 1.93 | 201 | 1.71 |
| 3D | 64 | 141 | 8.15 | 133 | 9.02 |
| 3D | 128 | 287 | 71.6 | 262 | 64.3 |

Layout:

- Two header rows: the first has the group headings "CG" and "GMRES", each spanning its two columns with a partial rule (`\cmidrule`) beneath it; the second has "Dimension", "N", then "Iter." and "Time (s)" under each group.
- "2D" and "3D" each span their two rows through `\multirow`.
- In each row, set the smaller of the two times in bold with `\textbf`, and no other number.
