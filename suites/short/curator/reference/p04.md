The right-hand side simplifies exactly: -1000(y-1)^2 + 1000(y^2-2y+1) - y = -y. It is not stiff, so RK45 is fine.
```python
import numpy as np
from scipy.integrate import solve_ivp
rhs = lambda t, y: -1000*(y-1)**2 + 1000*(y**2-2*y+1) - y
s = solve_ivp(rhs, [0, 10], [1.0], method="RK45", rtol=1e-9, atol=1e-12)
print(s.y[0, -1])
```
STIFF: no
