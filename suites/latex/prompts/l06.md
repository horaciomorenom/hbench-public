# L6. Theorem environments and cross-references

Write a complete document with `\section{Stability}` containing the following, in this order. Use `amsthm`, and `cleveref` for references (load `hyperref` too, in the right order).

- A definition, label `def:stable`: "A scheme is stable if its amplification factor satisfies $|g| \le 1$ for all wavenumbers."
- A lemma, label `lem:bound`: "The explicit Euler scheme for $y' = \lambda y$ has $g = 1 + \lambda \Delta t$."
- A theorem, label `thm:main`: "Explicit Euler is stable for real $\lambda < 0$ if and only if $\Delta t \le 2/|\lambda|$."
- A proof of the theorem: "By \<reference to the lemma\>, the condition $|1 + \lambda \Delta t| \le 1$ is required by \<reference to the definition\>. Solving this inequality gives the bound."
- A closing sentence after the proof: "This completes the analysis of \<reference to the theorem\>."

Numbering: all three environments share one counter and include the section number, so they print as Definition 1.1, Lemma 1.2 and Theorem 1.3. The definition's body is upright (the `definition` theorem style), and the lemma and theorem bodies italic. The references must print the type name automatically, like "Lemma 1.2".
