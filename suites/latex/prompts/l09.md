# L9. TikZ flowchart

Write a complete document with one `tikzpicture` flowchart of an adaptive mesh solver:

| Node name | Text | Shape |
|---|---|---|
| `mesh` | Generate mesh | rectangle |
| `assemble` | Assemble system | rectangle |
| `solve` | Solve system | rectangle |
| `check` | Error small? | diamond |
| `refine` | Refine mesh | rectangle |
| `output` | Write output | rounded rectangle |

Arrows: mesh to assemble, assemble to solve, solve to check, check to output labelled "yes", check to refine labelled "no", refine back to assemble.

Automatic checks read the picture, so:

- Use exactly those node names, as in `\node (mesh) ...`.
- Draw each arrow with its own `\draw`, from source to target, like `\draw[->] (mesh) -- (assemble);`. Don't use `\foreach` or `\graph`. Put a yes/no label in a `node` on its arrow.
- Nodes must not overlap, and the picture must fit inside the text width.
