```python
import numpy as np, math
def simpson(f, a, b, n):
    x = np.linspace(a, b, n + 1); h = (b - a) / n
    return h / 3 * (f(x[0]) + f(x[-1]) + 4 * f(x[1:-1:2]).sum() + 2 * f(x[2:-1:2]).sum())
f = lambda x: 1 / x
print(simpson(f, 1, 2, 10))
```
Theory: Simpson's rule is fourth order, so the error order is 4.
