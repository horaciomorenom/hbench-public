```python
import numpy as np
def conduction(N, T=0.005, cfl=0.4):
    dx = 1 / N; xc = (np.arange(N) + 0.5) * dx
    u = 1 + 2 * np.exp(-((xc - 0.5) / 0.05) ** 2); t = 0.0
    while t < T - 1e-15:
        k = u**2.5
        dt = min(cfl * dx**2 / (2 * k.max()), T - t)
        kf = 0.5 * (k[1:] + k[:-1])
        F = np.zeros(N + 1); F[1:-1] = -kf * (u[1:] - u[:-1]) / dx
        u = u - dt * (F[1:] - F[:-1]) / dx; t += dt
    return xc, u
```
dt = cfl dx^2 / (2 max kappa) with cfl <= 1 keeps each update a convex combination (positivity); flux form with zero boundary flux conserves sum(u).
