# L12. pgfplots convergence plot

Write a complete document with a `pgfplots` log-log plot of this mesh convergence data:

| h | P1 error | P2 error |
|---|---|---|
| 0.2 | 3.1e-2 | 4.2e-3 |
| 0.1 | 7.9e-3 | 5.4e-4 |
| 0.05 | 2.0e-3 | 6.8e-5 |
| 0.025 | 5.0e-4 | 8.5e-6 |

- Both axes logarithmic, x label "Mesh size $h$", y label "$L^2$ error", a major grid, and a legend.
- The two data series with markers, with legend entries "P1" and "P2".
- A third series: a dashed reference line of slope 2 passing through the point h = 0.2, error = 6.2e-2 (so it sits above the data), legend entry "slope 2".
- Set `\pgfplotsset{compat=...}` to a numeric version, 1.18 or lower.
- The axis goes in a `figure` with the caption "Convergence under mesh refinement".
