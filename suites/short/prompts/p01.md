# P1. Convergence-order plot (plotting code)

Write a complete Python function `plot_convergence(h, err, title="Convergence")` using
matplotlib and numpy that takes arrays of mesh sizes `h` and errors `err`, fits the
observed convergence order by least squares in log-log space, and draws a
publication-quality figure: log-log axes, markers for the data, a dashed fit line,
labeled axes, a legend, and an annotation of the observed order. Return `(order, fig)`.
