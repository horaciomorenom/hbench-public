# L10. TikZ weighted graph and its spanning tree

Write a complete document with one `tikzpicture` of this undirected weighted graph, with circular nodes `a`, `b`, `c`, `d`, `e`, `f` (node names and printed text are the same letters):

| Edge | Weight | | Edge | Weight |
|---|---|---|---|---|
| a-b | 4 | | c-e | 3 |
| a-c | 2 | | d-e | 7 |
| b-c | 5 | | d-f | 6 |
| b-d | 10 | | e-f | 9 |
| c-d | 8 | | | |

- Work out the minimum spanning tree. Define a TikZ style named `mst` (thick and coloured) and apply it to exactly the edges of the tree.
- Put the picture in a `figure` with a caption that ends "total weight W", where W is the tree's total weight as a number.

Automatic checks read the picture, so:

- Draw each edge with its own `\draw`, with the weight in a `node` on it: `\draw[mst] (a) -- node[above] {4} (b);`. Don't use `\foreach` or `\graph`, and draw each edge only once.
- Place the nodes so that none overlap. Try to avoid edges crossing.
