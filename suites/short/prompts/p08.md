# P8. Linear Hasegawa-Mima waves (derive, then implement)

The linearized Hasegawa-Mima equation is `q_t + v* φ_y = 0` with `q = ∇²φ - φ`, on a
doubly periodic domain of side `L = 20π`, `v* = 1`. (a) Derive the dispersion relation
ω(kx, ky) for a plane wave. (b) Implement a pseudo-spectral solver (FFT in space, RK4 in
time) on a 32×32 grid, starting from `φ = cos(kx x + ky y)` with `kx = 2π·3/L`,
`ky = 2π·2/L`, `dt = 0.1`, to t = 100. (c) Compare to the exact solution and report the
relative L2 error.

Interface for automatic checking: also define `solve_hm(N=32, dt=0.1, T=100.0)` returning the final `phi` as an (N, N) numpy array indexed `[i, j]` for `x = i*L/N`, `y = j*L/N`, and
`omega(kx, ky, v_star=1.0)` returning your ω for a wave `φ = cos(kx x + ky y - ω t)`.
